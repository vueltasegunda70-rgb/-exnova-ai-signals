# Exnova AI Signals

Aplicación web gratuita de análisis técnico experimental para velas OTC de 1 minuto.

## Funciones
- Indicadores EMA 9, EMA 21, RSI 14 y MACD.
- Señal orientativa CALL, PUT o ESPERAR.
- Historial local en el dispositivo.
- Interfaz adaptable a móviles.

## Limitaciones y seguridad
Esta versión no se conecta a Exnova, no obtiene cotizaciones en vivo y no ejecuta operaciones. Requiere pegar manualmente velas del gráfico. Los datos OTC de Exnova pueden ser exclusivos y no coincidir con fuentes externas. No introduzcas contraseñas, cookies ni claves de acceso. Las señales son experimentales, no están validadas y no garantizan resultados. Prueba primero en una cuenta demo.

## Publicar con GitHub Pages
En el repositorio abre Settings > Pages. En Build and deployment selecciona Deploy from a branch, rama main y carpeta /(root), luego Save. Espera a que GitHub publique el sitio.
